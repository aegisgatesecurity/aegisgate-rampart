## Lessons Learned (This Session)

### Release Pipeline Gotchas
1. **cosign sign-blob v2 API**: Uses `--output-certificate`/`--output-signature`, NOT `--certificate`/`--signature` (v1 API)
2. **cosign keyless in CI**: Requires `permissions: id-token: write` for GitHub OIDC token. Without it, falls back to device flow (browser) which times out after 300s → `expired_token`
3. **download-artifact@v4**: With no pattern, downloads ALL artifacts including Docker build metadata which fails. Always use `pattern: rampart-*`
4. **softprops/action-gh-release@v2**: Races on re-upload to existing releases. Add `continue-on-error: true` and `fail_on_unmatched_files: false`
5. **GitHub Actions trigger limitation**: Actions don't trigger other actions. A release created by workflow A won't trigger workflow B's `release: published` event. Use `workflow_dispatch` for testing.

### Debian Packaging Gotchas
6. **Control file requires Version field**: dpkg-deb will fail with "missing Version field" if absent
7. **Control file requires trailing newline**: dpkg-deb will fail with "end of file during value of field 'Description'"
8. **Description format**: Dash-prefixed list items (` - item`) in continuation lines can confuse dpkg-deb parser. Keep description simple.
9. **Binary-only package**: Remove `Source:`, `Build-Depends:`, `Standards-Version:`, `Vcs-*` fields. Use `Architecture: amd64` not `any`. Remove `${shlibs:Depends}` substitution variables.

### RPM Packaging Gotchas
10. **Pre-built binary**: Remove `BuildRequires` for compilers. Make `%build` a no-op. Use local `Source0` filename, not remote URL.
11. **%setup macro**: Derives tarball filename from Source0 URL. If Source0 is `https://...v0.6.0.tar.gz`, it looks for `SOURCES/v0.6.0.tar.gz`. Use `Source0: aegisgate-rampart-%{version}.tar.gz` instead.

### CI/Code Quality
12. **staticcheck doesn't respect //nolint**: Unlike golangci-lint, standalone staticcheck ignores `//nolint` directives. Remove unused functions entirely.
13. **w.Write returns 2 values**: `_, _ = w.Write(...)` not `_ = w.Write(...)`. But `os.WriteFile` returns 1 value: `_ = os.WriteFile(...)` not `_, _ =`.
14. **defer with _**: `defer _ = os.Chmod(...)` is invalid Go. Use `defer func() { _ = os.Chmod(...) }()`.
