🚀 Rampart Mock AI API

This is a development mock API for testing AegisGate Rampart locally.

Available Endpoints

POST /v1/chat/completions

Simulates OpenAI Chat Completions API

POST /v1/completions

Simulates OpenAI Completions API

POST /v1/complete

Simulates Anthropic Completions API

POST /v1/models/gemini-pro:generateContent

Simulates Google AI GenerateContent API

Usage

Configure Rampart to proxy through this mock API:

rampart --port 8080

Then send requests through the proxy:

curl -x http://localhost:8080 \
  https://api.openai.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4", "messages": [{"role": "user", "content": "Hello"}]}'

Testing Detections

Send test payloads to trigger detections:

  • SSN: Include "123-45-6789" in your request
  • Credit Card: Include "4111-1111-1111-1111"
  • AWS Key: Include "AKIAIOSFODNN7EXAMPLE"
  • XSS: Include "<script>alert('xss')</script>"
